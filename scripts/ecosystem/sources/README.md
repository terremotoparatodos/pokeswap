# Event-only classification source (F4)

`pokemon_species.csv` is the exact source file from PokéAPI commit
`bc92d3b6029ef1abe9e7ad424c400b338f3c11fe`, at
<https://raw.githubusercontent.com/PokeAPI/pokeapi/bc92d3b6029ef1abe9e7ad424c400b338f3c11fe/data/v2/csv/pokemon_species.csv>.
SHA256: `e66e2eeb25fd3836b0ebab6bf87bbf01960aa3c0555e2bac495fa8393c5e0c45`.
Its BSD-3-Clause license is retained in `POKEAPI_LICENSE.md`.

PokéAPI is a community data authority, not an official service of The Pokémon Company.
The explicit `is_legendary` and `is_mythical` flags are documented at
<https://pokeapi.co/docs/v2#pokemon-species>. No classifications are inferred from numbers,
names, power, market value or model knowledge.

The input has 1,025 species; the generated runtime snapshot contains ONLY the 493
species already in PokeSwap's battle catalog, with identical IDs and canonical names.
Within that scope it has 26 legendary and 9 mythical species, exactly the same event-only
lists as fa14ab2. No pools, entries or balance values change. The existing veekun/Showdown
battle pipeline is untouched; this separately scoped snapshot supplies the missing flags.

`node scripts/ecosystem/event-classification.mjs --check` runs offline and validates
the input hash, flags, names, complete coverage and generated bytes. Runtime reads only
the generated compact snapshot. Uncovered species cannot become ordinary encounters.
